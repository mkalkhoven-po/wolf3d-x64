Put your Wolfenstein 3-D game files here (version 1.4):

  the shareware:     VSWAP.WL1, VGAGRAPH.WL1, VGAHEAD.WL1, VGADICT.WL1,
                     GAMEMAPS.WL1, MAPHEAD.WL1, AUDIOHED.WL1, AUDIOT.WL1
  the full version:  the same names, ending in .WL6

The game finds them here by itself. With both versions here it plays the
full version; keep the shareware in another folder and pick it with
--data <folder>.
