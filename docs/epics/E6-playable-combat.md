# E6 — Playable combat

## Goal
Actors, pickups, weapons; finishable shareware episode.

## User stories
- As a player, I can collect keys/ammo/health and fight guards/dogs.
- As a player, I can complete the shareware episode including level transitions and death/lives.

## Functional requirements
- FR-GAME-005–008
- FR-SAVE-001 (basic save/load mid-epic or trailing story)

## Exclusions
- Boss-edge polish beyond than needed to finish WL1
- Spear bosses
- DOS save compatibility

## Acceptance
- [ ] Shootables die; player can die and restart/life flow works
- [ ] Keys open locked doors
- [ ] Elevator / episode completion path works for shareware
- [ ] One full episode run documented as test notes
