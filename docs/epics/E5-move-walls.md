# E5 — Move & walls

## Goal
Software raycaster + player movement/collision; walk first shareware map.

## User stories
- As a player, I can walk through E1M1-style geometry and see textured walls.
- As a player, walls block movement; doors can open with the use key.

## Functional requirements
- FR-GAME-003, FR-GAME-004
- FR-IN-001, FR-IN-002
- FR-VID-001–003
- NFR-001, NFR-002

## Exclusions
- Enemies/combat (static props optional)
- Audio required
- Pushwall secrets can be minimal but doors required

## Acceptance
- [ ] Start map from menu
- [ ] Move/turn with keyboard; mouse turn if enabled
- [ ] Correct cardinal corridor layout vs DOSBox reference screenshots
- [ ] At least one door opens and is passable
