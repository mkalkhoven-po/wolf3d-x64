The first release of **Wolf3D x64**, a faithful port of id Software's *Wolfenstein 3-D* (1992) to 64-bit Windows and Linux, rebuilt from the original source code. This is a **preview**: everything is in, and the first players are the playtest. Version 1.0.0 follows once the bugs you find are fixed.

**You need your own game files** (version 1.4): the free shareware (episode 1, files ending `.WL1`) or the full version (six episodes, `.WL6`, as sold today on Steam or GOG). No game data is included.

## Download

| System | Package |
|--------|---------|
| **Windows** 10 / 11, 64-bit | `wolf3d-x64-0.9.0-windows-x64.zip`: unzip, put your game files in `data`, double-click `wolf3d.exe`. The exe is not signed yet, so Windows may say "Windows protected your PC": **More info**, then **Run anyway**. |
| **Linux** 64-bit (Ubuntu 22.04 or newer and the like) | `wolf3d-x64-0.9.0-linux-x64.tar.gz`: needs SDL2 (`sudo apt install libsdl2-2.0-0`); unpack, put your game files in `data`, run `./wolf3d`. |

Without files in `data` the game asks for the folder they are in, and remembers it. `SHA256SUMS.txt` has the checksums.

## What is in it

- The original engine in 16.16 fixed point at 70 Hz: the original AI, doors, pushwalls, renderer and random numbers; all eight original demos replay in sync.
- The original screens: rating screen, title, credits, high scores and demos; the whole control panel with ten named save slots; Get Psyched, the intermission tally, victory, high score entry and the death cam.
- Sound as on a Sound Blaster Pro: digitized effects placed left and right, AdLib music and effects through an OPL2 emulator written for this port.
- Added, apart from the game logic: game pads (twin stick), the mouse in the menus, separate music and effects volume, fill-the-screen scaling with sharp pixels, fullscreen (F11), F8 / F9 quick save and load.

## Found a bug?

Please open an [issue](https://github.com/mkalkhoven-po/wolf3d-x64/issues): what happened, which version (the shareware or the full version) and, on Windows, the file `wolf3d.log` from `%APPDATA%\Wolf3D-x64\`.
